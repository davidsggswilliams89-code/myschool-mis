Security

Platform-level security guidance.

Required production controls

  • Firebase Authentication for every private user.
  • Platform Super Admin role enforced by Firestore Security Rules.
  • Every college-specific record carries a permanent schoolId.
  • College Admins can access only their own school's data.
  • Never place Firebase Admin SDK service-account secrets in this HTML.
  • Use a trusted backend/Admin SDK to create privileged user accounts.
  • Keep audit records for important platform actions.
